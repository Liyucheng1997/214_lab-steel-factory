# 炼钢厂架构与流程模型（数字炼钢厂）

一个交互式网页模型，展示现代钢铁联合企业（长流程：高炉—转炉路线）的
系统架构、主要工序和冶金过程。

## 运行方式

在项目目录启动任意静态服务器，例如：

```
python -m http.server 8204
```

然后打开 http://localhost:8204

## 工艺路线（长流程 BF-BOF）

```
原料场 ─┬─→ 烧结厂 ──→ ┐
        ├─→ 球团厂 ──→ ├─→ 高炉(炼铁) → 铁水预处理(脱硫)
        └─→ 焦化厂 ──→ ┘        ↓
                        转炉(BOF 吹氧炼钢)
                                ↓
                  LF 钢包精炼 → RH 真空精炼
                                ↓
                        连铸机(钢水 → 板坯)
                                ↓
                        热轧厂(板坯 → 钢卷)
```

## 项目结构

- `index.html` — 页面骨架 + Three.js importmap（CDN 加载，需联网）
- `style.css`  — HUD 覆盖层样式（标题栏 / 仪表盘 / 详情卡）
- `data.js`    — 领域模型：各系统的设备、输入输出、化学反应、工艺参数
- `plant.js`   — 厂区 3D 建模：每个工序一个 build 函数（高炉/转炉/连铸机…）
- `main.js`    — 场景搭建、点击交互、相机飞行、一炉钢的 3D 生产模拟

## 操作方式

- 鼠标左键拖拽旋转，滚轮缩放，右键平移
- 点击任意建筑 → 弹出该工序的设备/反应/参数详情卡，相机飞过去
- 「▶ 开始一炉生产」→ 发光钢包沿主线依次经过 7 个工序，
  底部仪表盘实时显示温度与 C/S/P 成分，连铸后变板坯、热轧后变钢卷

## 核心冶金逻辑（模拟中体现）

| 工序 | 关键变化 |
|------|----------|
| 高炉 | 铁矿石被 CO 还原成铁水：温度≈1480°C，C≈4.3% |
| KR脱硫 | S 从 0.045% 降至 0.005%，温降约 30°C |
| 转炉 | 吹氧脱碳：C 4.3%→0.06%，氧化放热使温度升至 ≈1660°C |
| LF精炼 | 白渣脱硫、合金微调、电极加热保温 |
| RH真空 | 脱氢脱氮、真空碳脱氧，防止白点缺陷 |
| 连铸 | 钢水在结晶器中凝固成坯，液态→固态 |
| 热轧 | 板坯再加热到 1250°C 后轧成钢卷 |
