# 炼钢厂架构与流程模型（数字炼钢厂 3D）

一个交互式网页模型，用 Three.js 按真实比例（1 单位 = 1 米）还原现代钢铁联合企业
（长流程：高炉—转炉路线）的厂区、主要工序设备和冶金过程。

## 运行方式

在项目目录启动任意静态服务器，例如：

```
python -m http.server 8204
```

然后打开 http://localhost:8204 （Three.js 从 CDN 加载，需联网）

## 工艺路线（长流程 BF-BOF）

```
原料场 ─┬─→ 烧结厂 ──→ ┐
        ├─→ 球团厂 ──→ ├─→ 高炉(炼铁) → 铁水预处理(KR脱硫)
        └─→ 焦化厂 ──→ ┘        ↓
                        转炉(BOF 吹氧炼钢)
                                ↓
                  LF 钢包精炼 → RH 真空精炼
                                ↓
                        连铸机(钢水 → 板坯)
                                ↓
                        热轧厂(板坯 → 钢卷)
```

|------|------|

| `textures.js`| 程序化贴图：彩钢板（含法线）、混凝土、砖、锈蚀钢、料堆、熔体、温度渐变、粒子 |
| `kit.js`     | 建模工具箱：PBR 材质库、按材质合并几何的 `Kit`、H 型钢柱/桁架/格构/管道/栏杆/平台/楼梯/铁轨/通廊/烟囱/储罐/厂房/桥式起重机 |
| `effects.js` | GPU 粒子：烟、蒸汽、火焰、火花、水幕（运动全在着色器内计算） |

| `main.js`    | 渲染管线（阴影/描边/辉光/色调映射）、交互、昼夜切换、剖切、一炉钢生产模拟 |

## 建模要点

- **真实比例**：4000m³ 级高炉（炉缸—炉腹—炉身—炉喉剖面、32 个风口、环管、4 座顶燃式热风炉、
  上升管/下降管/重力除尘器、主皮带通廊）、梨形转炉 + 托圈 + 倾动装置 + 氧枪 + OG 烟道、
  双流弧形板坯连铸机（回转台、中间包、结晶器、扇形段夹辊）、热连轧（加热炉、R1/R2、F1~F7、
  层流冷却、卷取机）、焦炉（炉门/护炉柱/上升管/集气管/推焦机/熄焦车）、斗轮堆取料机等。
- **性能**：成千上万个构件按"材质 × 图层"合并成少量网格，贴图按世界坐标生成 UV；
  粒子全部在 GPU 计算；阴影相机跟随视点并按纹素对齐。
- **剖切**：厂房外壳单独成层。点击某个工序会自动剖开它的外壳；工具栏「剖切」可一次剖开全部厂房。
- **昼夜**：白天有雾霭与环境反射；夜景有窗灯、路灯光斑，高温设备辉光更明显。

## 操作方式

- 左键拖拽旋转，滚轮缩放（朝光标方向），右键平移
- 点击建筑或标注 → 描边高亮、剖开外壳、相机飞过去、弹出工序详情卡
- 工具栏：⌂ 全景 / ◫ 剖切 / 🏷 标注 / 🌙 夜景
- 「▶ 开始一炉生产」：鱼雷罐沿铁路把铁水送到 KR → 兑入钢包 → 天车吊运经转炉（吹氧、倾动出钢）、
  LF（电极起弧）、RH（钢包顶升、真空循环）→ 连铸回转台旋转到浇注位 → 板坯进加热炉、
  经粗轧精轧变长变薄、层流冷却 → 卷取成钢卷。底部仪表盘实时显示温度与 C/S/P 成分，并绘制趋势图。

## 核心冶金逻辑（模拟中体现）

| 工序 | 关键变化 |
|------|----------|
| 高炉 | 铁矿石被 CO 还原成铁水：温度≈1480°C，C≈4.3% |
| KR脱硫 | S 从 0.045% 降至 0.005%，温降约 30°C |
| 转炉 | 吹氧脱碳：C 4.3%→0.06%，氧化放热使温度升至 ≈1660°C |
| LF精炼 | 白渣脱硫、合金微调、电极加热保温 |
| RH真空 | 脱氢脱氮、真空碳脱氧，防止白点缺陷 |
| 连铸 | 钢水在结晶器中凝固成坯，液态→固态 |
| 热轧 | 板坯再加热到 1250°C 后轧成钢卷 |
